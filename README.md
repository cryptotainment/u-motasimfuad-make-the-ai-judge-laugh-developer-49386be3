# Make the AI Judge Laugh: Developer Excuses

One funny single-line excuse a developer gives when code breaks in production.

> Production is down because my hotfix for the last outage was tested on the server that caused the last outage.

`main.py` writes the line to `/output/entry.txt` (deterministic, 110 characters).
